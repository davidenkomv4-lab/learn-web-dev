# [Backend] Задание 1. Запись клиентов в салон

Решение в одном файле — [`main.py`](main.py).

## Что сделано

**Задание 1. Класс `Appointment`.**
`create_appointment` теперь возвращает объект класса `Appointment`,
а не словарь. Запись создаётся, только если заполнены все поля
(имя клиента, мастер, услуга, время), и мастер с услугой существуют.
Иначе функция возвращает `None` и ничего не добавляет в `appointments`.

**Задание 2. Часы работы салона.**
Записаться можно только с 08:00 до 20:00. Время вне этого интервала
(например, `00:00`) или в неверном формате — запись не создаётся.

## Как запустить

```bash
python main.py
```

Ожидаемый вывод:

```
=== Задание 1. Две корректные записи ===
Список записей:
Иванова А.А. 10:00
Петрова А.А. 11:00

=== Задание 1. Запись с незаполненным полем ===
0

=== Задание 2. Две записи в часы работы ===
Список записей:
Иванова А.А. 10:00
Петрова А.А. 11:00

=== Задание 2. Запись на 00:00 (салон закрыт) ===
0
```
