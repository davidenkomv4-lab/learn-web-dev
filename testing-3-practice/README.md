## Задание 3.1. Классы эквивалентности и граничные значения

### Поле «Номер телефона»

**Требование:** только российский мобильный номер в формате `+7 (ХХХ) ХХХ-ХХ-ХХ` — 11 цифр, начинается с `+7`.

**Допущения** (уточнить у проектировщика):
- российский **мобильный** номер — код оператора начинается с `9` (`+7 (9ХХ) …`);
- пользователь вводит цифры, а маска `+7 (___) ___-__-__` подставляет префикс и разделители.

#### Классы эквивалентности

| ID | Класс | Тип | Пример значения | Ожидаемый результат |
|---|---|---|---|---|
| P1 | Префикс +7, 10 цифр после него, код начинается с 9 (всего 11 цифр) | ✅ Валидный | `+7 (912) 345-67-89` | Номер принят |
| P2 | Пустое поле | ❌ Невалидный | `` | Ошибка «Введите номер телефона» |
| P3 | Меньше 11 цифр | ❌ Невалидный | `+7 (912) 345-67` | Ошибка «Номер введён не полностью» |
| P4 | Больше 11 цифр | ❌ Невалидный | `+7 (912) 345-67-890` | Лишняя цифра не вводится (маска ограничивает длину) |
| P5 | Другой код страны | ❌ Невалидный | `+380 (91) 234-56-78` | Ошибка формата / маска не даёт ввести |
| P6 | Начинается с 8 вместо +7 | ❌ Невалидный | `8 (912) 345-67-89` | Ошибка формата (или маска заменяет 8 на +7 — уточнить) |
| P7 | Не мобильный номер (код не на 9) | ❌ Невалидный | `+7 (495) 123-45-67` | Ошибка «Укажите мобильный номер» |
| P8 | Содержит буквы | ❌ Невалидный | `+7 (9аб) 345-67-89` | Буквы не вводятся |
| P9 | Содержит спецсимволы (кроме символов маски) | ❌ Невалидный | `+7 (912) 345#67*89` | Спецсимволы не вводятся |
| P10 | Только пробелы | ❌ Невалидный | `   ` | Ошибка «Введите номер телефона» |

#### Граничные значения

Граница — **количество цифр** (ровно 11):

| № | Значение | Цифр | Ожидаемый результат |
|---|---|---|---|
| BV-P1 | `+7 (912) 345-67-8` | 10 (на 1 меньше) | ❌ Ошибка «Номер введён не полностью», запись не подтверждается |
| BV-P2 | `+7 (912) 345-67-89` | 11 (ровно) | ✅ Номер принят |
| BV-P3 | `+7 (912) 345-67-890` | 12 (на 1 больше) | ❌ 12-я цифра не вводится, в поле остаётся `+7 (912) 345-67-89` |

Граница по **первой цифре кода оператора** (мобильный = 9):

| № | Значение | Ожидаемый результат |
|---|---|---|
| BV-P4 | `+7 (899) 999-99-99` | ❌ Ошибка «Укажите мобильный номер» |
| BV-P5 | `+7 (900) 000-00-00` | ✅ Номер принят (минимальный мобильный код) |
| BV-P6 | `+7 (999) 999-99-99` | ✅ Номер принят (максимальный мобильный код) |

### Поле «Ваше имя»

**Требование:** только буквы кириллицы, от 2 до 40 символов.

**Допущения** (уточнить у проектировщика):
- допустимы строчные и заглавные буквы, включая `ё` / `Ё`;
- пробел и дефис («Анна-Мария», «Анна Петрова») по требованию **не** являются буквами → невалидны;
- пробелы по краям строки обрезаются до проверки длины.

#### Классы эквивалентности

| ID | Класс | Тип | Пример значения | Ожидаемый результат |
|---|---|---|---|---|
| N1 | Кириллица, длина 2–40 | ✅ Валидный | `Анна` | Имя принято |
| N2 | Кириллица с буквой ё | ✅ Валидный | `Алёна` | Имя принято |
| N3 | Пустое поле | ❌ Невалидный | `` | Ошибка «Введите имя» |
| N4 | Длина меньше 2 | ❌ Невалидный | `А` | Ошибка «Имя должно содержать от 2 до 40 букв» |
| N5 | Длина больше 40 | ❌ Невалидный | 41 буква «А» | Ошибка длины (или 41-я буква не вводится) |
| N6 | Латиница | ❌ Невалидный | `Anna` | Ошибка «Используйте только русские буквы» |
| N7 | Смешанные алфавиты | ❌ Невалидный | `Аnна` (А и н — кириллица, n — латиница) | Ошибка «Используйте только русские буквы» |
| N8 | Цифры | ❌ Невалидный | `Анна2` | Ошибка «Имя может содержать только буквы» |
| N9 | Спецсимволы | ❌ Невалидный | `Анна!` | Ошибка «Имя может содержать только буквы» |
| N10 | Пробел или дефис внутри | ❌ Невалидный | `Анна-Мария` | Ошибка «Имя может содержать только буквы» |
| N11 | Только пробелы | ❌ Невалидный | `     ` | Ошибка «Введите имя» |

#### Граничные значения

Граница — **длина** (от 2 до 40):

| № | Значение | Длина | Ожидаемый результат |
|---|---|---|---|
| BV-N1 | `` | 0 | ❌ Ошибка «Введите имя» |
| BV-N2 | `А` | 1 | ❌ Ошибка длины |
| BV-N3 | `Ян` | 2 (минимум) | ✅ Имя принято |
| BV-N4 | `Яна` | 3 | ✅ Имя принято |
| BV-N5 | 39 букв `Аааа…а` | 39 | ✅ Имя принято |
| BV-N6 | 40 букв `Аааа…а` | 40 (максимум) | ✅ Имя принято |
| BV-N7 | 41 буква `Аааа…а` | 41 | ❌ Ошибка длины (или 41-я буква не вводится) |
| BV-N8 | ` Ян ` (пробелы по краям) | 2 после обрезки | ✅ Имя принято, сохраняется «Ян» |

## Задание 3.2. Таблица решений

**Правило:** запись подтверждается, только если заполнено «Ваше имя», заполнен «Номер телефона» и телефон валиден.

**Условия:**
- **C1** — поле «Ваше имя» заполнено;
- **C2** — поле «Номер телефона» заполнено;
- **C3** — номер телефона валиден (формат `+7 (9ХХ) ХХХ-ХХ-ХХ`, 11 цифр).

C3 имеет смысл только при заполненном телефоне: пустой телефон не может быть валидным.
Поэтому из 2³ = 8 комбинаций 2 невозможны (R4, R8), они отмечены прочерком.

|---|---|---|---|---|---|---|---|---|
| **C1.** Имя заполнено | Да | Да | Да | Да | Нет | Нет | Нет | Нет |
| **C2.** Телефон заполнен | Да | Да | Нет | Нет | Да | Да | Нет | Нет |
| **C3.** Телефон валиден | Да | Нет | Нет | *Да* | Да | Нет | Нет | *Да* |
| **A1.** Запись подтверждена, открыто окно «Запись подтверждена» | ✅ | | | — | | | | — |
| **A2.** Ошибка у поля «Ваше имя»: «Введите имя» | | | | — | ✅ | ✅ | ✅ | — |
| **A3.** Ошибка у поля «Номер телефона»: «Введите номер телефона» | | | ✅ | — | | | ✅ | — |
| **A4.** Ошибка у поля «Номер телефона»: «Неверный формат номера» | | ✅ | | — | | ✅ | | — |
